# Pelin nimi: Pixel Code
**Altina Krasniqi**

Pelin idea:
Pelaaja yrittää auttaa pelin sisälle hukkunutta tyttöä takaisin kotiin.
Pelaajan täytyy liikkua ja käydä jokaisessa huoneessa eli maassa jotta löytää tarvittavat esineet. 

Pelin tavoite:
Pelaajan täytyy löytää kaikki esineet, jotka ovat avain, kirja ja kirje. Kartaa on valmiiksi inventaariossa. 
Kun pelaaja on löytänyt kaikki tarvittavat esineet, pelaaja pääsee takaisin kotiin sekä voittaa pelin. 

Pelin käyttö:
Peli käynnistetään valitsemalla uusi peli tai jatka tallennettua peliä.
Pelin aikana pelaaja valitsee toimintoja numeroilla.
Pelissä liikutaan vastaamalla kysymyksiin ja valitsemalla sen vaihtoehdon minkä itse haluaa.
Pelissä saa itsekkin lisätä inventaarioon jonkun itse valitseman esineen. 
Pelissä pystyy tallentamaan ja lopettamaan peliä halutessa. 
Peli sisältää: 
Ohjeiden lukemisen.
Ympäristön tutkimisen.
Inventaarion tarkistamisen.
liikkumista eri paikkoihin.
Pelin tallennuksen.
Pelin lopetuksen. 

Peli sisältää nämä huoneet/paikat:
Koodilaakson josta peli alkaa.
Pixelimaan
Muistivuodon
Roskapostikuilun

Pelin esineenä on:
-Kartta
-Avain
-Kirja
-Kirje

Kestävän kehityksen tavoite:
Kestävän kehityksen tavoitteena on hyvä koulutus sillä pelissä pelaaja harjoittelee erilaisten valintojen tekoa, ongelman ratkaisemista sekä päättelemistä. Pelaajan täytyy käydä eri paikoissa sekä löytää pyydetyt esineet päästääkseen pelin tavoitteeseen.
